# Tennis Simulator

3D-симулятор большого тенниса на Unity (URP, новая Input System, Cinemachine).

Что есть:

- матч против ИИ трёх уровней или против второго игрока, с меню, паузой и итогами;
- подача по правилам и теннисный счёт с тай-брейком;
- модели и анимации игроков;
- выставочный корт (хард) на стадионе примерно на 5 тысяч мест со зрителями и табло;
- звук.

## Запуск

1. Откройте папку проекта в Unity **6000.6.7f1** (нужна активированная лицензия).
2. При первом открытии `ProjectBuilder` сам создаст настройки URP, конфиги, материалы и сцену `Assets/TennisSim/Scenes/Prototype.unity` и откроет её.
3. Нажмите Play. Подключённый геймпад подхватывается автоматически.

Пересобрать сцену и ассеты: меню **Tennis → Rebuild Project Assets and Scene**.

Собрать игру для Windows: меню **Tennis → Build Windows Player**. Результат — `Build/Windows/TennisSimulator.exe`. В git билды не попадают; папку `Build/Windows` можно копировать только целиком.

Игра запускается на весь экран в разрешении монитора. **Alt+Enter** переключает в оконный режим, окно можно растягивать. Выбранный режим Unity запоминает.

## Как играть

**Меню.** Игра открывается в меню, за ним идёт показательный матч двух ИИ.

- Выберите соперника: ИИ лёгкий, средний или сильный, либо второй игрок.
- Выберите длину матча: короткий сет до 4 геймов, один сет или до двух выигранных сетов.
- Выберите время: день или вечер при прожекторах.
- Стрелки или крестовина листают варианты, A / Enter подтверждает.
- **Esc / Start** ставит игру на паузу. Из паузы можно выйти в меню.
- После матча показывается счёт по сетам и кнопка «Реванш».

**Удар:** нажать кнопку — подготовка, отпустить — замах. Ракетка приходит в точку контакта через 0,14 с после отпускания.

- Отпустили вовремя — **Perfect**: мяч быстрее и точнее.
- Держали кнопку через мяч — автозамах с опозданием, **Good**: играть можно всегда, но это не лучший результат.
- Ошиблись моментом или стоите далеко от мяча — **Poor** или промах.

Пока кнопка зажата, стик по-прежнему двигает игрока, а точка контакта подстраивается под его положение. Если стик отпущен или до мяча иначе не успеть, игрок сам бежит к точке контакта, а стик задаёт прицел. **F3** отключает автопозиционирование: движение полностью ручное.

**Удары разные не только по кнопке:**

- Тайминг уводит мяч в сторону: рано — поперёк корпуса (форхенд влево), поздно — в другую сторону.
- Высокий отскок бьётся сильнее, низкий мяч приходится поднимать, и он медленнее.
- Мяч, взятый на вытянутой руке, становится **защитным**: медленный, высоко над сеткой, в середину.
- Мяч, взятый сразу после отскока у самой земли, — **с полулёта**: меньше силы, больше ошибок.
- Плоский удар и удар с лёта используют скорость мяча соперника.

**Подача:**

1. До подброса стик ведёт подающего вдоль задней линии на его половине.
2. Нажатие — подброс, отпускание — удар. Лучший момент — когда мяч опускается через точку удара. Если держать кнопку, удар выйдет сам, чуть поздно (Good).
3. Пока мяч в воздухе, стик целит: влево/вправо по квадрату подачи, вперёд/назад — глубина.

| Подача | Кнопка | Характер |
|---|---|---|
| Плоская | H / X | Самая быстрая (до 190 км/ч), чаще ошибки |
| Резаная | U / B | Закручивается влево от подающего |
| Кик | остальные кнопки | Медленнее, высоко над сеткой, почти не ошибается: для второй подачи |

Действуют правила: мяч должен попасть в квадрат по диагонали, касание сетки с попаданием в квадрат — переподача, две ошибки подряд — проигранное очко. Принимающий бьёт только после отскока. Счёт теннисный: 15-30-40, ровно, больше. Подача переходит после каждого гейма. Сет идёт до 6 геймов с разницей в два, при 6:6 играется тай-брейк до 7 очков. В тай-брейке подача меняется через каждые два очка.

Стороны не меняются: человек всегда играет на ближней половине, как во многих теннисных играх.

| Действие | Клавиатура | Геймпад | Игрок 2 (клавиатура) |
|---|---|---|---|
| Движение и прицел | WASD | Левый стик | Стрелки |
| Только прицел | — | Правый стик | — |
| Ускорение | Shift | RT | Правый Shift |
| Авто (топспин, сторона по мячу) | Space | A / Cross | Num 0 |
| Удар справа | J | Крестовина → | Num 1 |
| Удар слева | K | Крестовина ← | Num 2 |
| С лёта | L | RB | Num 3 |
| Резаный | U | B / Circle | Num 4 |
| Плоский | H | X / Square | Num 5 |
| Свеча | I | Y / Triangle | Num 6 |
| Укороченный | O | LB | Num 7 |

Смэш не имеет своей кнопки: высокий мяч, взятый над головой, становится смэшем автоматически.

Первый геймпад управляет ближним игроком, второй — дальним, если в меню выбран второй игрок.

Клавиши для настройки механик во время матча:

- **F1** — отладочная подсказка (FPS, разрешение, последний удар, скорость, вращение, раскладка);
- **F2** — передать дальнего игрока человеку или ИИ;
- **F3** — включить или выключить автопозиционирование;
- **F4** — сменить уровень ИИ.

## Графика

Модели, анимации и текстуры корта собираются скриптами из `Tools/Blender` (нужен Blender 5.2). Результат лежит в `Assets/TennisSim/Art`. Запускать из корня проекта; `<work>` — любая папка для промежуточных файлов:

```
blender -b --factory-startup --python Tools/Blender/prepare_meshes.py -- <player.glb> <racket.glb> <work> Assets/TennisSim/Art/Player
blender -b --factory-startup --python Tools/Blender/rig_and_animate.py -- <work> Assets/TennisSim/Art/Player
blender -b --factory-startup --python Tools/Blender/remove_logo.py -- <work> Assets/TennisSim/Art/Player
blender -b --factory-startup --python Tools/Blender/make_court_textures.py -- Assets/TennisSim/Art/Court
blender -b --factory-startup --python Tools/Blender/make_stadium.py -- Assets/TennisSim/Art/Stadium
blender -b --factory-startup --python Tools/Blender/make_crowd_atlas.py -- <work> Assets/TennisSim/Art/Player Assets/TennisSim/Art/Stadium
```

Пути лучше передавать абсолютные: Blender ищет относительные от своей рабочей папки. Атлас зрителей рендерится из `<work>/player_rigged.blend`, поэтому запускается после второго шага.

После этого выполните **Tennis → Rebuild Project Assets and Scene**.

Исходные GLB весят по 76 МБ и в репозиторий не входят. Первый шаг без них не запустить, но остальные работают, если промежуточные файлы первого шага сохранились.

`remove_logo.py` закрашивает фирменные знаки отсканированной формы: на груди, шортах, гетрах, напульсниках и сзади на футболке. Запускать после `prepare_meshes.py`, который пишет текстуры заново.

## Звук

Все звуки синтезируются скриптом, записей и чужих лицензий нет:

```
python Tools/Audio/make_sounds.py Assets/TennisSim/Audio
```

Нужен numpy; подойдёт и Python, встроенный в Blender. Удар ракеткой собран из звона струн, щелчка мяча и удара обода. Аплодисменты — из тысяч отдельных хлопков, гул и крики трибун — из шума, окрашенного под гласные. `AudioManager` выбирает звук удара по типу и качеству контакта, громкость отскока по скорости мяча; трибуны затихают на розыгрыш.

## Тесты

В Unity: **Window → General → Test Runner**.

| Набор | Что проверяет |
|---|---|
| `Tests/EditMode` | Физика мяча, решатель ударов, качество контакта, судейство, счёт и тай-брейк, целые матчи ИИ разных уровней |
| `Tests/Input` | Все привязки геймпада и клавиатуры через виртуальные устройства |
| `Tests/PlayMode` | Настоящая сцена: ИИ играют, камера держит мяч и ближнего игрока, зрители реагируют, меню и пауза с геймпада, конец матча. Снимки в `Logs/Screenshots` |
